# 파운데이션 레이어 — 화면보다 먼저

순서를 지키세요. 각 단계가 끝나야 다음 단계에서 "값" 대신 "이름"으로 말할 수 있습니다.

| 단계 | 파일 | 완료 기준 |
|---|---|---|
| 0 | 코드베이스 감사 | Tailwind 버전(v3/v4), 라우터(app/pages), 기존 토큰·폰트 충돌 확인 |
| 1 | `globals.css` + `fonts.ts` | 빈 페이지에 `bg-paper text-ink` + 4개 폰트가 뜬다 |
| 2 | `lib/format.ts` | 가격·등락률·거래량·시각이 스크린샷과 **글자 단위로** 동일 |
| 3 | `lib/types.ts` | 백엔드 6.1~6.4 반환값이 타입에 1:1로 들어간다 |
| 4 | 프리미티브 6종 (아래) | 스토리북/데모 페이지에서 6종이 다 보인다 |
| 5 | 화면 (2a 종목 상세부터) | PROMPTS.md 스테이지 1~ |

## 왜 이 순서인가
- 색·간격·라운드(0)는 **에디토리얼 톤의 정체성**입니다. 화면부터 만들면 매 화면에서 재협상하게 됩니다.
- 숫자 포맷은 이 서비스의 핵심 콘텐츠입니다. `tabular-nums` + 단위 규칙이 흔들리면 표가 전부 흔들립니다.
- 프리미티브 6종이 전체 화면의 약 70%를 덮습니다.

## 프리미티브 6종 (4단계에서 이것만 만들 것)
1. **SectionLabel** — mono 9.5~10.5px, uppercase, `tracking-label`, muted. 모든 섹션 머리.
2. **Delta** — 등락 표시. props: `value`, `percent`, `inverted?`(반전 배경 위), `size`. 상승 빨강/하락 파랑 규칙을 **여기 한 곳에만** 둔다.
3. **Chip** — 정규화 심볼·시장·섹터. `variant: 'outline' | 'solid'`, radius 0.
4. **Hairline / DottedRow** — `border-b` 헤어라인, 리스트 행 점선. 직접 border 쓰지 말 것.
5. **Sparkline** — SVG, props: `points`, `w`, `h`, `direction`. 데스크탑 76×24 / 검색 92×26 / 관심종목 104×28.
6. **StatRow** — 라벨/값 2열 행 (투자 지표, 시장 개요, AI 근거).

버튼·탭·토글은 화면 만들면서 뽑아도 늦지 않습니다. 미리 만들지 마세요.

## 하지 말 것
- `rounded-*` 사용 (예외: 알림 토글 pill, 모바일 시트 상단).
- 컴포넌트 안에서 hex 리터럴 사용 — 전부 토큰 클래스/변수로.
- 상승/하락 색 분기를 Delta 밖에서 다시 쓰기.
