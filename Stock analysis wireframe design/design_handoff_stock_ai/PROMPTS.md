## 1. 종목 상세 (디자인 2a) — 가장 먼저

```
README의 "3. 종목 상세 (2a 메인)" 섹션과 screenshots/2a-detail-editorial.png 를 기준으로
/stocks/[symbol] 페이지를 만들어줘. 이번 단계에서 AI 판단 패널은 제외하고, 버튼만 놔둬(비활성).

먼저 계획을 보여줘:
- 라우트/파일 구조, 서버·클라이언트 컴포넌트 경계
- 컴포넌트 분해(헤드라인, 차트, 탭, 뉴스 리스트, 우측 지표 레일)
- 목 데이터 타입 정의(Quote, Candle, Metric, NewsItem, AnalystReport)

계획에 동의하면 구현할게. 지금은 실제 API 대신 타입만 맞춘 목 데이터로 붙여줘.
지켜야 할 것:
- 좌우 그리드 1fr / 292px, gap 28px
- 종목명 46px Noto Serif KR 700, 가격 44px IBM Plex Mono, 숫자는 전부 tabular-nums
- 모든 radius 0, 헤어라인 rgba(26,26,23,.14), 점선 구분선 rgba(26,26,23,.22)
- 우측 지표 패널 배경 #f4efe4
```

차트는 별도로:

```
이제 상세 페이지의 차트를 lightweight-charts 로 구현해줘. README "차트 (직접 구현했음 — 동작 사양)"의 동작을 모두 만족해야 해:
캔들 + 거래량 서브차트(높이 19%, opacity .3) + MA20/MA60 + 볼린저밴드(20,2) 면,
골든/데드크로스 GC/DC 마커, 커서 십자선 + OHLCV 툴팁(#1a1a17 배경, mono 10.5px),
휠로 기간 확대·축소(18~240봉), 우상단 1M/3M/6M/1Y 프리셋.
MA/BB/교차 계산은 순수 함수로 분리하고 단위 테스트를 붙여줘.
```

검수:

```
screenshots/2a-detail-editorial.png 와 지금 구현한 화면을 나란히 비교해서 다른 점을 목록으로 뽑아줘.
글자 크기·굵기·자간, 여백, 선 색과 굵기, 정렬(숫자 우측정렬 여부)까지 확인하고 차이는 고쳐줘.
```

## 2. AI 판단 패널 (디자인 2a 드로어)

```
README "4. AI 판단"과 screenshots/2a-ai-drawer-open.png 를 기준으로 AI 판단 드로어를 붙여줘.

- 폭 438px, 배경 #f4efe4, 좌측 보더 2px #1a1a17, slideIn .32s cubic-bezier(.2,.8,.2,1)
- 열림 상태는 URL 쿼리(?ai=1)와 동기화
- 4단계 진행 표시: 주가 조회 → 뉴스·리포트 수집 → 에이전트 의견 3건 → 최종 판단
  라벨 "{단계} · n/4 단계", 진행 바 3px, width .4s ease
- 에이전트 카드는 도착 순서대로 append + fadeUp .34s, 대기 자리에는 3줄 스켈레톤
- 최종 판단 블록: #1a1a17 배경, 판단 34px 명조, 신뢰도 5칸 인디케이터, 근거 ＋/－ 3줄, 면책 문구
- LLM 실패 시 "규칙 기반 판단" 배지 + 다시 시도 버튼 (screenshots/1d-states-fallback.png 참고)

서버는 아직 없으니 단계 이벤트를 흘려주는 목 스트리밍(ReadableStream) 라우트 핸들러를 만들어서 UI가 실제로 스트리밍으로 동작하게 해줘. 나중에 백엔드 generate_stock_advice 로 교체할 지점을 주석으로 표시해줘.
```
