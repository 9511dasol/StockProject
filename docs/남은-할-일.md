### P0-1. 커밋되지 않은 마이그레이션이 이미 DB 에 적용돼 있다 (S) ✅ 확인

DB 의 `alembic_version` 이 저장소에 없는 리비전을 가리킨다. 실측:

```
alembic current  →  c9b3e7d21a08 (head)     ← 미추적 파일
alembic heads    →  c9b3e7d21a08 (head)
사슬 끝 두 칸    →  f2c9b47ad831 → a4d72f9e51c3 → c9b3e7d21a08
                                   └── 둘 다 git 에 없다
```

`git checkout .` / `git clean -fd` 한 번이나 디스크 사고로 파일이 사라지면 `upgrade`·`check`·
`downgrade` 가 전부 `Can't locate revision` 으로 죽고, 되돌릴 방법은 `alembic_version` 을 손으로
고치고 컬럼·테이블을 손으로 지우는 것뿐이다. 관리자·스크리너 기능 전체(서비스·리포지토리·
스키마·화면)가 로컬 디스크 하나에만 있다.

- 근거: [a4d72f9e51c3](../back/alembic/versions/a4d72f9e51c3_add_screener_metrics_to_listed_companies.py) · [c9b3e7d21a08](../back/alembic/versions/c9b3e7d21a08_add_admin_role_and_audit_log.py) (둘 다 미추적) · [작업노트.md:2135](작업노트.md#L2135)
- 할 일: [`COMMIT_NOTES.md`](../COMMIT_NOTES.md) 의 대기 항목을 커밋한다(12개 준비돼 있다).

### P0-3. LIKE 메타문자로 엉뚱한 관심종목이 지워진다 (S) ✅ 확인

`find_by_code` 가 `symbol LIKE '{code}%'` 로 찾고 **정렬 없이** `first()` 를 쓴다. 경로
파라미터는 `code: str` 로 검증이 없다.

```
DELETE /api/v1/watchlist/%     → 그 소유자의 전 행에 매치 → 임의의 한 종목이 지워진다 → 200
PATCH  /api/v1/watchlist/_5930 → 엉뚱한 종목의 그룹·알림·보유수량이 바뀐다 → 200
```

오류가 나지 않는다. "6자리라 겹칠 수 없다"는 [주석의 전제](../back/app/repositories/watchlist.py#L55)가
숫자 검증이 없어 성립하지 않는다.

- 근거: [repositories/watchlist.py:60](../back/app/repositories/watchlist.py#L60)·[:86](../back/app/repositories/watchlist.py#L86) · [endpoints/watchlist.py:76](../back/app/api/v1/endpoints/watchlist.py#L76) · 같은 뿌리: [listed_company.py:148](../back/app/repositories/listed_company.py#L148) (초성 `%{initials}%`) · [utils/text.py:49](../back/app/utils/text.py#L49) (비한글 통과) · [repositories/admin.py:263](../back/app/repositories/admin.py#L263) (관리자 검색)
- 할 일: 경로 파라미터에 `Path(pattern=r"^\d{6}$")`. `find_by_code` 는 LIKE 를 없애고
  `symbol.in_([f"{code}.KS", f"{code}.KQ"])`. 남는 ILIKE 는 `%`·`_`·`\` 이스케이프 헬퍼 +
  `escape="\\"`. `get_initial_consonants` 는 한글 초성·영숫자만 남긴다.
  **회귀 테스트로 `%`·`_` 를 넣은 요청이 아무것도 지우지 않는 것을 고정한다.**

### P0-7. `listed_companies` 를 만드는 마이그레이션이 사슬에 없다 (M) ✅ 확인

리비전 뿌리(`61b513b1f58a`, `down_revision=None`)가 그 테이블에 **컬럼을 더하는 것으로
시작한다.** 사슬 8개 전체에 `create_table("listed_companies")` 가 0건이다 — 여덟 컬럼과 unique
인덱스는 alembic 이력에 한 번도 등장하지 않는다. 지금 테이블이 존재하는 유일한 이유는
`create_all` 기본값이 True 이기 때문이다.

문서대로 `DB_CREATE_ALL_ON_STARTUP=false` + `alembic upgrade head` 로 새 Supabase 를 붙이면
**첫 리비전에서 `UndefinedTable` 로 멈춘다** — 신규 구축과 복구·이관 경로가 막혀 있다.
테스트도 `create_all` 을 쓰므로 이 사슬을 한 번도 태우지 않는다.

- 근거: [61b513b1f58a:24](../back/alembic/versions/61b513b1f58a_add_market_cap_to_listed_companies.py#L24)·[:33](../back/alembic/versions/61b513b1f58a_add_market_cap_to_listed_companies.py#L33) · [models/listed_company.py:19](../back/app/models/listed_company.py#L19) · [back/README.md:203](../back/README.md#L203) · [conftest.py:189](../back/tests/conftest.py#L189)
- 할 일: `61b513b1f58a` **앞에** baseline 리비전을 넣어 컬럼 8개 + `symbol` unique + `search_*`
  인덱스를 `create_table` 로 적고, 이미 적용된 DB 는 [`d5e8a1c60f47`](../back/alembic/versions/d5e8a1c60f47_add_document_chunks.py) 처럼
  `inspect(...).get_table_names()` 로 존재를 인정하고 넘어간다. 빈 DB → `upgrade head` →
  `check` 를 CI 잡으로 한 번 돌린다.

## 손대지 말 것 — 의도적으로 배제했고 지금도 유효한 판단

1. **검색 팔레트 ⇥ 와 서버 저장소 통합** — 10회차가 근거까지 적어 유보했다(로컬에 쌓인 것을
   서버로 올릴지 사용자에게 물어야 해서 별도 결정이 필요하다). 지금 요구되는 것은
   **안내 문구·⇥ 힌트를 사실로 맞추는 것뿐**(P1-18)이다. 통합을 밀지 말 것.
2. **공개 yfinance 경로에 새 키를 더 붙이지 말 것** — "잠글 이유가 있는 곳만 잠근다 / 키가 닿는
   표면을 넓히지 않는다" 는 근거는 유효하다([api/auth.py:9](../back/app/api/auth.py#L9)).
   약해진 것은 "남이 불러도 잃는 것이 없다" 쪽뿐이므로, 대응은 키가 아니라 **심볼 검증·서버
   캐시·백오프**다(P0-6).
3. **관리자 화면은 배치를 돌리지 않는다** — 관측과 실행을 분리한 판단이다. `/admin` 조회가 배치
   트리거가 되게 만들지 말고, 명시적 트리거(CLI 또는 `POST /admin/batches/snapshot`)를 따로 둔다.
4. **`browse/tokens.ts` 와 `screener/tokens.ts` 를 합치지 말 것** — 6열(시세)과 7열(지표)로 열
   정의가 실제로 다르다. 같은 이유로 **스크리너 지표 컬럼에 인덱스를 걸지 않은 17회차 결정**도
   2,747행 규모에서는 그대로 둔다.
5. **프런트 `ADMIN_EMAILS`(SEED_ADMINS) 마스터키를 없애지 말 것** — DB 와 무관하게 관리자를
   인정하는 이 경로가 "아무도 못 들어가는 상태" 를 막는 유일한 복구 수단이고, P2-2(마지막 관리자
   경쟁 조건)의 실질 완충이다.
6. **LangGraph 체크포인터는 계속 보류** — 한 요청이 짧게 끝난다는 근거는 유효하다. 단, 그 근거를
   코드로 강제해야 한다(P1-15) — **보류의 전제를 지키는 일이지 되돌리는 일이 아니다.**
